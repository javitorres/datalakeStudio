API PUBLISHING · DOCKER INSTALLATION

A saved query is your API.

No exports, no glue services, no scheduled dumps. In the Docker installation, add a parameter with {braces}, hit publish, and Datalake Studio serves live data over REST.

SAVED SQL QUERY carsByBrand
SELECT brand, model, price
FROM   cars
WHERE  brand = {brand}
ORDER BY price DESC
→
LIVE REST ENDPOINT GET
$ curl ".../api/carsByBrand?brand=FORD"
[ { "brand": "FORD", "model": "Focus", "price": 18400 }, … ]
